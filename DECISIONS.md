# Решения по механикам и устройству

Здесь записано, что выбрано там, где ТЗ оставило выбор. Любое решение можно пересмотреть; числа из симуляции меняются в `SimConfig.kt`.

## Этап 0 — каркас

| Тема | Решение | Почему |
| --- | --- | --- |
| Инструменты сборки | Gradle 9.7.1, Android Gradle Plugin 9.3.3, Kotlin 2.4.21; compileSdk и targetSdk 37 (Android 17), minSdk 26 | Самая новая связка, которую Kotlin официально поддерживает: Kotlin 2.4.21 проверен с AGP до 9.3.1 и Gradle до 9.7.0. AGP 9.3 уже умеет API 37. Kotlin компилируется встроенной поддержкой AGP 9, без плагина kotlin-android |
| Идентификатор приложения | `io.github.torintheone.petri` | Менять нельзя: с другим идентификатором Android считает приложение новым и не обновляет старое |
| Название и версия | `petri.appName` и `petri.version` в `gradle.properties`; при сборке по тегу версия берётся из тега | Одна константа на название, как требует ТЗ. versionCode = 1 + major·1 000 000 + minor·1 000 + patch, поэтому каждая следующая версия ставится поверх предыдущей |
| Единицы мира | Координаты в микрометрах, ось y направлена вверх, гравитация будет вдоль −y; время в игровых часах | Клетка массой 3,6 нг имеет диаметр около 25 мкм, чашка 1 мм — 1000 мкм: числа удобно читать |
| Шаг симуляции | 1 игровая минута (`STEP_HOURS`) | Совпадает с примером в ТЗ; подшаги для связей добавятся на этапе 1 |
| Скорость «Наблюдения» | 1 игровой час за 1 секунду (`OBSERVE_HOURS_PER_SECOND`) | Деление раз в 0,5–3 часа видно глазом как событие раз в несколько секунд. Подберём на телефоне |
| Скорость «Инкубации» | Без верхнего предела: шаги идут подряд, снимок для экрана — 60 раз в секунду | ТЗ требует максимальную скорость, которую тянет устройство. На пустой чашке возраст растёт очень быстро — это нормально |
| Отставание в «Наблюдении» | Не больше 4 шагов догоняния за кадр (`MAX_CATCH_UP_STEPS`), остальное отбрасывается | Медленное устройство будет идти медленнее реального времени вместо того, чтобы зависнуть |
| Диаметр чашки по умолчанию | 1 мм | Середина диапазона по ощущениям: помещается около 1000 взрослых клеток. Подберём при тестах этапа 2 |
| Передача снимков рендеру | Тройной буфер без блокировок (`TripleBuffer`) | Вариант двойной буферизации из ТЗ, при котором ни симуляция, ни рендер никогда не ждут друг друга |
| Свёрнутое приложение | Симуляция стоит, пока приложение не на экране | Экономит батарею; автосохранение при уходе в фон появится вместе с сохранением (этап 3) |
| Перерисовка | Только когда пришёл новый снимок или сдвинулась камера | В «Заморозке» экран не тратит батарею |
| Жесты | Один палец оставлен для инструментов; два пальца одновременно меняют зум и сдвигают вид; двойной тап — вся чашка | Как в ТЗ. Зум ограничен: от половины вписанной чашки до 40 мкм на короткой стороне экрана. Центр вида не уходит за край чашки, поэтому её нельзя потерять |
| Поворот экрана | Activity не пересоздаётся (`configChanges`), в альбомной ориентации вкладки слева | Сохраняется GL-контекст, симуляция не прерывается |
| Часы в интерфейсе | Подпись «h», как в ТЗ | Единица из оригинала и из ТЗ |
| Оформление | Всегда тёмная тема | Тёмный фон чашки задаёт тон всему приложению |
| Нативная библиотека из Compose | `libandroidx.graphics.path.so` исключена из APK (`packaging.jniLibs.excludes`) | Её приносит зависимость Compose `androidx.graphics:graphics-path`. Она нужна только для перебора сегментов `Path`, а приложение так пути не обходит: чашка рисуется через OpenGL. Так выполняется требование ТЗ «в APK нет папки lib/». Проверка в CI по-прежнему падает на любой другой нативной библиотеке |
| Выпуск релизов | Релиз с тегом `v0.<этап>.0` создаётся на странице Releases; workflow срабатывает и на пуш тега, и на публикацию релиза, прикладывает APK и подставляет описание из CHANGELOG.md | Облачная среда Claude может отправлять код только в свою ветку: пуш тега отклоняется (HTTP 403) |
| Подпись без ключа | Если секретов нет, release подписывается debug-ключом с предупреждением в логе и в описании релиза. Если ключ есть, но не хватает пароля или имени, сборка падает с понятной ошибкой | Сборка без ключа всё равно ставится начисто; а наполовину настроенный ключ лучше заметить сразу |

## Этапы 1–2 — физика, деление, питание

| Тема | Решение | Почему |
| --- | --- | --- |
| Размер клетки | Площадь пропорциональна массе: r = 6,588·√m мкм. Клетка 3,6 нг имеет диаметр 25 мкм | Растущая клетка заметно увеличивается, а при делении пополам площадь сохраняется |
| Шаг физики | 4 подшага на игровую минуту. Жёсткость пружин учитывается неявно (система 2×2 на клетку), вязкое трение тоже | Явная схема при жёстких связях «взрывала» колонию. Неявная остаётся устойчивой при любой жёсткости из настроек |
| Силы | Жёсткость пружин умножается на массу клетки | Лёгкие и тяжёлые клетки ведут себя одинаково, связи не рвутся от разницы масс |
| Связь (адгезин) | Пружина по линии центров, длина покоя = сумма радиусов + зазор до 10 мкм («Длина адгезина»). Точка крепления хранит угол на мембране; угловая пружина разворачивает клетку так, чтобы точка смотрела на партнёра | Так организм держит форму, которую задаёт геном, а не случайные толчки соседей |
| Разрыв связи | Если связь растянута больше чем на 45 мкм сверх длины покоя | Пинцетом можно оторвать клетку от организма |
| Наследование связей при делении | Связь матери достаётся тому потомку, с чьей стороны от плоскости деления лежит её точка крепления. Точка крепления сохраняет направление в мире | Прямая цепочка остаётся прямой, а угол потомка 15° даёт ровную дугу (проверено тестами) |
| Деление | Не чаще раза в 0,5 h. Порог массы деления 0 означает «делиться по возрасту», максимум означает «никогда не делиться». Деление тратит 0,3 нитратов | Простые правила, которые легко увидеть в превью генома |
| Пища | По умолчанию появляется в случайных местах и медленно дрейфует (плавное блуждание с «памятью» направления 15 мин). Клетка съедает частицу при касании. Частица, появившаяся прямо на фагоците, съедается сразу | Без дрейфа неподвижные фагоциты быстро съедали всё вокруг и голодали. С дрейфом колония живёт и растёт |
| Свет | Источник — точка на краю чашки, яркость спадает от неё по закону Гаусса; «Ширина света» 1 — ровный свет по всей чашке | Узкий луч заставляет колонию фотоцитов тянуться к источнику, как требует критерий этапа 2 |
| Расход | Каждый тип тратит свою массу в час (таблица в `SimConfig.baseCostPerHour`), всё умножается на 0,4. Солёность 0..1 меняет расход в 1,5..0,5 раза | Соотношения взяты из описаний типов, общий множитель подобран так, чтобы фагоциты на стартовой чашке росли |
| Обмен по связям | Связанные клетки выравнивают отношение «масса / приоритет» со скоростью 3 доли разницы в час; масса при этом не появляется и не исчезает | Критерий этапа 2: суммарная масса организма сохраняется (тест) |
| Стартовая чашка | 30 фагоцитов с геномом по умолчанию и пища на половину предела | Чашка сразу живая; пустую можно будет получить кнопкой «Стерилизовать» на вкладке «Среда» |
| Синтезатор | Сажает клетку массой 3 нг с текущим геномом в точку тапа | Взрослая клетка сразу может делиться |
| Пинцет | В «Заморозке» клетка переносится точно под палец. В остальных режимах её тянет к пальцу пружина, поэтому связанный организм тащится целиком | В замороженной чашке иначе ничего не двигалось бы |
| Подкормка | Тап по клетке добавляет 0,5 нг (не больше предела массы), тап по пустому месту кладёт частицу пищи | Один инструмент для обоих случаев из ТЗ |
| Диагностика | Тап выбирает клетку, камера сразу следует за ней; «Следить» включает и выключает слежение. Щипок или двойной тап выключают слежение | Двигать камеру и одновременно следить нельзя: пальцы победили бы камеру |
| Число видов | Сколько разных геномов сейчас живёт в чашке | До мутаций (этап 5) это число посаженных геномов |
| Сигналы в карточке | S1–S4 показываются, но до этапа 6 всегда равны 0 | Карточка сразу имеет вид из ТЗ |

## Этап 3 — редактор генома и генбанк

| Тема | Решение | Почему |
| --- | --- | --- |
| Файл генома | JSON: `formatVersion` первым полем, затем имя, начальный режим и 40 режимов со всеми параметрами, включая значения по умолчанию | Файл, которым поделились, значит одно и то же в любой будущей версии |
| Файл чашки | gzip(JSON) с полным состоянием: настройки, часы, генератор случайных чисел, клетки, связи вместе со списком свободных мест, пища, геномы, график. Значения, равные значениям по умолчанию, не пишутся | Загруженная чашка продолжает жить точно так же, как сохранённая (проверено тестом). Без значений по умолчанию геном в чашке занимает в несколько раз меньше места. Тест `FormatsTest` следит за значениями по умолчанию: если их поменять, тест напомнит поднять версию формата и написать миграцию |
| Миграции | Цепочка шагов «версия N → N+1» над JSON. Файл новее приложения не читается, а вызывает сообщение «обновите приложение» | Старые файлы всегда открываются в новых версиях |
| Неполные и битые файлы | Недостающие режимы генома заполняются новыми, лишние отбрасываются, значения вне диапазона зажимаются, неизвестные типы клеток становятся фагоцитами. Чашка с противоречиями (связь с несуществующей клеткой, NaN) не загружается | Чинится то, что можно починить без догадок. Сломанная чашка дала бы сбой позже, поэтому лучше сразу понятная ошибка |
| Имена файлов | Имя генома или чашки, записанное в Base64 (URL-вариант). Имя — до 40 символов | Любое имя, в том числе с «/» и эмодзи, работает в любой файловой системе. Сохранение под тем же именем заменяет файл |
| Запись файлов | Сначала во временный файл, потом переименование | Если телефон выключится посреди записи, старое сохранение останется целым |
| Превью роста | Отдельный мир с ростом 1 нг/h у каждой клетки, без расхода и смерти от голода, до 64 клеток, первая клетка «передом» вверх. Пересчёт через 300 мс после последнего изменения, целиком за 0–47 h | 48 часов колонии из 64 клеток считаются за 60 мс на компьютере, поэтому показывать по частям не нужно |
| Масштаб превью | Один на все часы, по самому большому кадру | Когда ползунок двигается, видно, как организм растёт |
| Сетка поиска соседей | Покрывает только прямоугольник вокруг клеток, а не всю чашку | Превью в чашке 3 мм ускорилось в 6 раз; в обычной чашке скорость не изменилась |
| Миниатюры в генбанке | Организм в момент, когда вырос до 64 клеток, но не позже 24 h; считаются в фоне при открытии | Отдельные файлы с картинками не нужны |
| Примеры в генбанке | Четыре генома записываются при первом запуске. Если их удалить, они не появятся снова | Новичку есть с чего начать, а генбанк остаётся под контролем человека |
| Синтезатор и редактор | Синтезатор всегда сажает геном из редактора. «Копировать геном» и «С микроскопа» кладут геном клетки в редактор | Один «текущий» геном вместо двух — проще понять |
| Автосохранение | При уходе в фон: чашка и геном редактора в папку `autosave`; при запуске они возвращаются | Требование ТЗ |
| Настройки приложения (DataStore) | Пока не используются: настроек приложения ещё нет | Хранилище подключим вместе с первой настройкой, чтобы не тянуть лишнюю зависимость |

## Этап 4 — базовые типы и параметры среды

| Тема | Решение | Почему |
| --- | --- | --- |
| Сила жгутика | 6 нг·мкм/мин² при «Силе плавания» 1. Двухклеточный «Пловец» с силой 0,6 проходит около 100 мкм за игровой час | С прежней силой 2 пловец едва полз (15 мкм/ч), а трение о дно съедало почти всю тягу |
| Хвост флагеллоцита | Жгутик не работает, если связь прикреплена в пределах 60° от его «зада». Гибель от этого — отдельное правило «Склеенный жгутик убивает клетку», по умолчанию выключено | ТЗ просит сделать гибель настраиваемой; без неё проще строить организмы |
| Организм | Клетки одного организма — потомки одной клетки, разделившиеся с адгезином. Потомок без связей начинает новый организм. Склейка глюоцитом организмы не объединяет | Девороцит и глюоцит отличают «своих» от «чужих» по этому номеру |
| Девороцит | Высасывает 6 нг/ч из каждой касающейся клетки другого организма, себе оставляет 80% | Незащищённую колонию девороциты съедают за пару часов (тест) |
| Кератиноцит | Защищает себя и клетки, напрямую связанные с ним, от девороцитов, глюоцитов, вироцитов и секретов | Как в ТЗ. Колония с кератиноцитами переживает девороцитов (тест) |
| Глюоцит | Клеит к себе касающиеся клетки других организмов и стенку, пока у него меньше 5 связей. По связи глюоцита тоже течёт еда | Поэтому глюоцит с высоким приоритетом питания работает как паразит, как и описано в ТЗ |
| Буйоцит и гравитация | Плотность обычной клетки 0,6, буйоцита — его программируемое значение 0–1. Сила = гравитация × (плотность клетки − плотность среды на этой высоте) × масса | Обычные клетки при гравитации медленно тонут в среде по умолчанию, буйоциты тонут или всплывают (тест) |
| Обмен по связям | Поток еды не больше свободного места у клетки-получателя | Иначе полная клетка «сжигала» поток, и липоцит терял запас впустую |
| Изменение среды | Новые настройки сразу применяются к идущей чашке. При уменьшении чашки клетки и пища за новой стенкой переносятся внутрь | Стенка не должна давить клетки, оказавшиеся снаружи |
| Ползунки среды | Всегда с шагом: 25 делений для 0–1, вязкость по 10, диаметр по 0,25 мм, числа клеток и пищи по 100 | Удобно попадать в круглые значения |
| Новые примеры в генбанке | Список уже предложенных примеров хранится в `presets.txt`. Новый пример добавляется один раз и не заменяет геном с таким же именем | Удалённый пример не возвращается, а после обновления появляются новые |

## Этап 5 — эволюция

| Тема | Решение | Почему |
| --- | --- | --- |
| Частота мутаций | Вероятность за час для клетки: 0,1·r + 1,9·r², где r — радиация. При 0,04 это 0,7 мутации на 100 клеток в час, при 1 — две мутации на клетку в час | Критерий ТЗ: при ~0,04 заметные изменения за десятки часов, при 1 геном быстро разрушается (оба проверены тестами) |
| Гибель от радиации | 0,1·r² в час | Малая вероятность; заметна только при сильной радиации |
| Какой режим мутирует | В 80% случаев — режим, который организм использует (достижимый из начального или текущего режима), в 20% — любой из 40 | Иначе большая часть мутаций попадала бы в неиспользуемые режимы и эволюция шла бы незаметно. «Спящие» мутации в других режимах всё равно случаются |
| Точечная мутация | Гауссов сдвиг одного числа режима, разброс 8% диапазона; углы проходят через 360°, остальное обрезается по краям диапазона; числа подбираются по типу клетки (сила плавания мутирует только у флагеллоцита) | Как в ТЗ |
| Структурная мутация | 30% всех мутаций, если они разрешены. Варианты поровну: смена типа (из генофонда), смена режима потомка 1 или 2, переключение флага (адгезин, связи, зеркальность, приоритизация), копирование режима поверх другого, смена входа программируемого значения | Как в ТЗ; смена входа даёт эволюции «переподключать» нервные цепочки этапа 6 |
| Пустой генофонд | Тип клеток не меняется, заражения нет | Самое простое и предсказуемое поведение |
| Случайный геном при заражении | От 1 до 4 используемых режимов со случайными типами из генофонда, ссылками друг на друга, массами деления 1,5–3,4 нг и углами, кратными 15° | Новичок обычно вырастает во что-то осмысленное, а не умирает сразу |
| Виды | Вид — отдельный геном в памяти. Одинаковые геномы от разных мутаций считаются одним видом | Как в ТЗ: «id генома и id родителя дают счётчик видов» |
| Ползунок радиации | Двигается по √r: середина ползунка — 0,25, первые деления — около 0,002, 0,007, 0,016, 0,028, 0,043 | Интересные значения — маленькие, им нужна большая часть длины ползунка |

## Этап 6 — сигналы

| Тема | Решение | Почему |
| --- | --- | --- |
| Модель сигнала | Источник тянет уровень своего канала к своему выходу (±1), остальные клетки — к 0, со скоростью 6 в час (около 10 минут). Каждая связь за шаг выравнивает уровни двух клеток на долю до 0,5, делённую на число связей у более «занятой» клетки | Устойчиво при любом числе связей и даёт то, что требует ТЗ: сигнал течёт по связям, затухает и разбавляется у клетки с многими связями (тесты) |
| Знак стереоцита | Раздражитель слева от «переда» стереоцита даёт плюс, справа — минус | В ТЗ написано «справа — плюс», но в контрольном «умном пловце» из ТЗ правый флагеллоцит берёт a ≈ +0,76. Сильнее толкающий правый жгутик поворачивает организм влево, то есть с «правым плюсом» пловец уплывал бы от пищи. Знак выбран так, чтобы контрольный сценарий ТЗ работал как описано (тест «the smart swimmer turns towards food»). Заодно «плюс слева» совпадает с отсчётом всех углов генома против часовой стрелки |
| Сила «запаха» | Сумма по объектам в радиусе 160 мкм с весом 1 / (1 + (d / 40 мкм)²); у стереоцита каждый вклад умножается на синус угла к его «переду». Выход = чувствительность × 2 × сила, не больше ±1 | Формула из ТЗ; 40 мкм — около двух клеток |
| Скорость и стенка | «Скорость»: собственная скорость / 5 мкм в минуту. «Стенка»: 1 / (1 + (зазор / 40 мкм)²); у стереоцита — с учётом стороны | Самые простые разумные шкалы |
| Генератор нейроцита | Синус с частотой до 2 колебаний в игровой час: в канал A идёт +sin, в канал B — −sin. Фаза считается от возраста клетки | «Синус между двумя каналами» из ТЗ; у разных клеток фазы разные |
| Стемоцит | Каждый шаг проверяет путь 1, затем путь 2; при значении больше 0,5 переходит в режим пути, если ещё не в нём | Как в ТЗ |
| Секроцит | Действует на клетки, чья поверхность ближе 25 мкм к его поверхности. Цианид отнимает до 4 нг/ч у чужих незащищённых клеток; липаза с вероятностью до 6 раз в час снимает оболочку с частицы или растворяет чужой незащищённый липоцит в пищу целиком; сигнальное вещество поднимает выбранный канал у незащищённых соседей; запах пищи сенсоры считают за 3 частицы пищи. Без нитратов секреции нет | Простые и заметные в игре эффекты. Свой организм цианид не трогает, иначе секроцит отравил бы сам себя |
| Остатки клеток | Погибшая клетка распадается на частицы не тяжелее 1 нг, разбросанные по её площади | Растворённый липоцит иначе превращался бы в одну гигантскую частицу |
| «Умный пловец» в генбанке | Ряд «рот – хвост – стереоцит – хвост – рот»: все деления боковые (угол деления 0°), поэтому каждая связь однозначно уходит к нужному потомку. Соотношения деления 0,4 и 1/3 дают пять одинаковых клеток | Пловец из ТЗ (стереоцит и два флагеллоцита) сам не ест; два фагоцита по краям кормят его и отпочковывают семена |

## Этап 7 — вироцит, гамета, график и полировка

| Тема | Решение | Почему |
| --- | --- | --- |
| Вироцит | Заражает касающуюся незащищённую клетку чужого организма с вероятностью 2 раза в час: копирует «Режим заражённой клетки» и все режимы, достижимые из него, в геном жертвы на те же номера и переводит жертву в этот режим. Другие вироциты не заражаются | Мгновенное заражение при касании делало бы вирус непобедимым. Новый геном жертвы — обычная «мутация» со своим номером |
| Гамета | Сливается с первой касающейся гаметой другого организма. Каждый режим берётся от случайного родителя, начальный режим и «Режим после слияния» — от гаметы, которая обрабатывается первой. Массы складываются (не больше предела типа), нитраты усредняются, новая клетка — новый организм | Простейшая рекомбинация из ТЗ: «каждый режим берётся от одного из родителей» |
| Совместимость гамет | Совместима любая гамета другого организма | Самое простое правило; гаметы одного организма не сливаются |
| Цилиоцит | При касании клетки или стенки реснички со стороны касания толкают клетку вдоль поверхности: 1,2 нг·мкм/мин² при скорости 1, соседу — равная обратная сила | Клетка ползает по соседям и стенке, как в ТЗ (тест) |
| График численности | Точка каждые 0,5 игровых часа, последние 480 точек (240 h). У каждой линии свой масштаб, в легенде — текущее и наибольшее значения | Все три линии читаются, даже когда пищи в десять раз больше, чем клеток |
| Приоритет потока симуляции | На единицу ниже обычного | «Инкубация» забирает всю свободную мощность, но экран и касания не тормозят |
| «О приложении» | Диалог внизу вкладки «Среда»: версия, короткое описание, сведения о том, что всё сделано с нуля | Название оригинальной игры нигде в приложении не упоминается (требование ТЗ) |
| Автосохранение | Включается только после того, как прошлое автосохранение загружено; записи идут по одной; команды, отправленные симуляции перед закрытием, выполняются после остановки её потока | Иначе ранний уход в фон записывал пустую стартовую чашку поверх настоящей, а выход кнопкой «Назад» мог потерять последнее сохранение |

## Версия 0.8.0 — новый интерфейс

| Тема | Решение | Почему |
| --- | --- | --- |
| Стиль | Тёмная тема «лабораторный прибор»: фон почти чёрный с синевой, панели из «дымчатого стекла» (над чашкой полупрозрачные) с каймой в 1 dp, один бирюзовый акцент для включённого и выбранного, янтарный — для паузы и минуса, салатовый — для пищи (как в самой чашке). Шрифт системный, цифры табличные (`tnum`), технические подписи — моноширинные | Просьба пользователя: «красивый интерфейс в научном стиле». Свой шрифт в APK не кладём: системный хорошо читается и не увеличивает размер |
| Верх «Микроскопа» | Вместо панели состояния и кнопок времени — панель показаний (возраст, клетки, пища, виды); нажатие раскрывает график численности под ней | Старый текст сверху ничего не делал при нажатии, а подписи кнопок времени обрезались |
| Кнопки времени | В доке инструментов: ⏸/▶ переключает «Заморозку» и «Наблюдение», ⏩ включает и выключает «Инкубацию». Три режима ТЗ сохранены | Значки понятны без слов и помещаются на узком экране; кнопки под большим пальцем |
| Подсказка инструмента | Название и одна строка о том, что делает инструмент или режим времени, 4,5 с после выбора и при открытии вкладки | Значки без подписей помещаются в одну строку с кнопками времени, а подсказка объясняет их, не загораживая чашку постоянно |
| Ползунки | Двигаются только горизонтальным перетаскиванием, начатым в любом месте полосы, на столько же, на сколько сдвинулся палец; нажатие на полосу значение не меняет. Кнопки «−»/«+»: шаг — одно деление привязки, без привязки — 1/100 диапазона; удержание дольше 0,4 с повторяет шаг каждые 70 мс. Под полосой шкала: каждое деление, если делений не больше 25, иначе десятые доли | Стандартный ползунок прыгал к месту касания, и прокрутка длинного списка сбивала значения; кнопки дают точный шаг |
| Справка к параметру | Значок «i» после названия вместо подчёркивания | Подчёркивание не выглядело нажимаемым |
| Группы на «Среде» | Сворачиваются нажатием на заголовок, при открытии вкладки все развёрнуты | Длинный список легче листать, но ничего не прячется по умолчанию |
| Масштабная линейка | Самая длинная из длин 1, 2, 5 × 10ⁿ мкм, которая занимает не больше 96 dp (в превью — 72 dp); от 1000 мкм — в миллиметрах | Как на снимках микроскопа: круглое число и короткая черта |
| Превью генома | Сетка через 1, 2, 5 × 10ⁿ мкм (не чаще 28 dp), каждая пятая линия ярче; кнопка ▶ показывает рост с часа 0 по 47, по 0,11 с на час | Сетка показывает размеры организма; проигрывание удобнее, чем листать ползунок |
| Цвет клетки в карточке | `CellInfo` дополнен цветом режима клетки | Цвет помогает узнать клетку на экране |
| Вкладка и график | Хранятся в модели экрана, а не в самих экранах | Иначе график закрывался при каждом переключении вкладок |
| Скриншоты | Процесс Screenshots в GitHub Actions собирает APK, запускает его на эмуляторе Android 15 (Pixel 6), открывает экраны параметрами запуска `petri.tab`, `petri.preset`, `petri.inspect` и коммитит уменьшенные снимки в `docs/screenshots` от имени github-actions. Запускается, когда меняется код приложения | Видно, как выглядит каждая версия, без установки на телефон; параметры запуска надёжнее нажатий по координатам |
