# ТЗ для Claude Code: симулятор эволюции клеток для Android

Oct 21, 2026 · @Pony

## Цель и рамки

Нужно с нуля написать нативное Android-приложение — песочницу эволюции малоклеточных организмов по мотивам игры Cell Lab: Evolution Sandbox (Petter Säterskog, последнее обновление 2018). Приложение должно ставиться как обычный APK на современные 64-битные телефоны. Целевое устройство — Poco X7 Pro: его процессор не исполняет 32-битный код, поэтому оригинал на нём не запускается.

Суть игры: игрок программирует геном — набор «режимов», каждый из которых задаёт тип клетки, правила её деления и режимы дочерних клеток. Из одной клетки вырастает организм; он питается, размножается и мутирует в настраиваемой среде, а игрок наблюдает естественный отбор.

Правовые рамки, обязательные для исполнителя:

- Код пишется полностью с нуля. APK оригинала не декомпилировать и не дизассемблировать; не копировать его код, графику, звуки и тексты справки.
- Не использовать название «Cell Lab» и логотип. Рабочее название приложения — **Petri** (меняется одной константой).
- Повторяем механики и ощущение игры, а не точные числа оригинала. Все численные константы выносятся в один конфиг и подбираются на глаз.

Вне рамок версии 1: 45 сюжетных челленджей, сетевые функции, импорт файлов `.genome` оригинала (их формат неизвестен).

## Стек и сборка

Приложение пишется на Kotlin без нативного кода (без NDK), поэтому оно работает на любом 64-битном Android без отдельной сборки под архитектуру. APK собирается в облаке через GitHub Actions, чтобы пользователю не нужен был ПК с Android Studio.

| Слой | Решение |
| --- | --- |
| Язык | Kotlin 2.x, JVM toolchain 17, Gradle Kotlin DSL + version catalog |
| Интерфейс | Jetpack Compose (Material 3): меню, редактор генома, настройки |
| Рендер чашки | OpenGL ES 3.0 через `GLSurfaceView` в `AndroidView`; все клетки — один инстансированный draw-call, круг и детали рисует фрагментный шейдер |
| Симуляция | Отдельный Gradle-модуль `sim` на чистом Kotlin/JVM, без `android.*`; тестируется на JVM |
| Данные | kotlinx.serialization (JSON), сжатие gzip для снимков мира |
| SDK | minSdk 26, targetSdk — последний стабильный на момент сборки |
| ABI | Нативных библиотек нет; в APK не должно быть папки `lib/` |

Структура репозитория:

```
app/                       — Activity, Compose-экраны, GL-рендер
sim/                       — мир, физика, геном, мутации (чистый Kotlin)
sim/src/test/              — юнит-тесты симуляции
.github/workflows/build.yml — сборка APK
SPEC.md                    — это ТЗ
DECISIONS.md               — принятые по ходу решения по механикам
```

Сборка и установка:

- Тип сборки `release` с R8: debug-сборки на ART заметно медленнее, а симуляции важна скорость.
- Подпись ключом из GitHub Secrets (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`). Один постоянный ключ нужен, чтобы новые версии ставились поверх старых без удаления данных. Если секретов нет — подписывать debug-ключом и писать об этом в логе.
- Workflow: на каждый push — сборка и тесты; на тег `v*` — GitHub Release с прикреплённым `petri-<версия>.apk`. Со страницы Releases файл удобно скачать прямо на телефоне.
- В README — пошаговая инструкция для неспециалиста: как создать ключ, добавить секреты, поставить тег и установить APK (разрешить установку из неизвестных источников).

## Мир: чашка Петри и среда

Мир — двумерный вертикальный срез круглой чашки Петри: гравитация тянет вниз, свет падает с края чашки. Время симуляции идёт в игровых часах (h); клетка живёт десятки–сотни часов, деление возможно не чаще раза в 0,5 h.

Режимы времени: «Заморозка» (всё стоит), «Наблюдение» (обычная скорость), «Инкубация» (максимальная скорость, которую тянет устройство; в оригинале примерно в 100 раз быстрее наблюдения).

Параметры среды (все в `SubstrateSettings`, значения по умолчанию подбираются при тестах):

| Параметр | Диапазон | Что делает |
| --- | --- | --- |
| Диаметр чашки | 0,5–3 мм | Размер мира; клетка массой 3,6 нг ≈ 1/40 диаметра 1 мм |
| Макс. число клеток | 100–5000 | При достижении предела новые деления запрещены |
| Макс. число частиц пищи | 100–5000 | Ограничение спавна пищи |
| Скорость появления пищи | 0–1 | Сколько частиц пищи появляется в час |
| Размер частицы пищи | 0–1 | Сколько массы даёт частица фагоциту |
| Кучность пищи | 0–1 | Сколько частиц появляется группой |
| Размер кучи | 0–1 | Разброс частиц внутри группы |
| Оболочка пищи | 0–1 | Липидная оболочка: такую пищу (красная) фагоцит ест только после липазы от секроцита |
| Подвижная пища | вкл/выкл | Частицы пищи подчиняются вязкости, гравитации и толчкам |
| Яркость света | 0–1 | Интенсивность источника |
| Ширина света | 0–1 | 0 — узкий луч у источника, 1 — освещена вся чашка |
| Вращение света | 0–1 | Скорость обхода источника по краю чашки; 0 — стоит на месте |
| Вязкость | 0–200 | Коэффициент стоксова сопротивления: F = −k·r·v |
| Динамическое трение | 0–1 | Трение о дно при движении |
| Статическое трение | 0–1 | Порог, ниже которого покоящаяся клетка не сдвигается |
| Гравитация | 0–1 | Сила для клеток, чья плотность отличается от плотности среды |
| Плотность среды | 0–1 | Ниже — клетки тонут, выше — всплывают |
| Градиент плотности | 0–1 | Плотность растёт ко дну |
| Солёность | 0–1 | Множитель базового расхода: низкая солёность — клетки тратят больше |
| Нитраты | 0–1 | Скорость поглощения нитратов из среды |
| Радиация | 0–1 | Частота мутаций и повреждений (раздел «Мутации») |
| Только точечные мутации | вкл/выкл | Запрещает смену типа клетки и режимов потомков |
| Старение | вкл/выкл | Клетки умирают в возрасте 240 h |
| Гибель на краю | вкл/выкл | Клетка, коснувшаяся стенки, погибает |
| Заражение случайными клетками | вкл/выкл | Периодически добавляет клетки со случайным геномом |
| Генофонд | набор типов | Какие типы клеток могут появиться при заражении и мутациях |

Модель света: источник стоит на краю чашки под углом θ(t), θ растёт со скоростью вращения (сброс — сверху). Освещённость точки I = яркость × exp(−d² / 2σ²), где d — расстояние до источника, а σ растёт с шириной; при ширине 1 освещённость равномерная.

Действия с чашкой: сохранить, загрузить сохранённое, стерилизовать (убить все клетки и пищу, обнулить возраст, настройки и геном сохраняются).

Инструменты микроскопа: синтезатор (поставить клетку с текущим геномом), пинцет (перетащить клетку пальцем), подкормка (добавить массу клетке или положить пищу), удаление клетки, диагностика (следить за клеткой, показать её состояние, скопировать геном).

## Физика и обмен веществ

Клетка — упругий диск с ориентацией: у неё есть «перёд» (стрелка), от которого отсчитываются все углы генома. Масса клетки — это её запас энергии: клетка растёт, когда получает больше, чем тратит, и сжимается в обратном случае.

**Состояние клетки** (хранить как Structure of Arrays на `FloatArray`/`IntArray`, без объектов на клетку в горячем цикле): позиция, скорость, угол, угловая скорость, масса, возраст, индекс режима, ссылка на геном, запас нитратов 0–1, сигналы S1–S4, флаги (защищена, отравлена, гамета), список связей.

**Размер.** Радиус r = k·√масса (площадь пропорциональна массе). Рабочий диапазон массы 0–3,6 нг; вставленная клетка стартует с \~3 нг. Липоцит может накапливать до 3× больше за счёт «жира».

**Интегрирование.** Фиксированный шаг dt (например 1 игровая минута) с подшагами для устойчивости связей, полунеявный Эйлер. Соседей искать через пространственную хеш-сетку с ячейкой ≈ максимальному диаметру клетки.

**Силы:**

- Отталкивание при перекрытии — пружина по глубине перекрытия; жёсткость растёт с параметром «Цитоскелет» режима.
- Вязкое сопротивление среды и трение о дно (параметры субстрата).
- Гравитация × (плотность клетки − плотность среды на этой высоте); у обычной клетки плотность фиксированная, у буйоцита — программируемая.
- Стенка чашки — жёсткая окружность; при «Гибели на краю» касание убивает клетку.

**Адгезионные связи.** Связь соединяет две точки крепления на поверхностях клеток; угол крепления хранится в системе координат каждой клетки. Это даёт и расстояние, и сохранение взаимной ориентации — без этого организмы не держат форму и жгутик не будет перекрываться.

- Линейная пружина с длиной покоя «Длина адгезина» и жёсткостью «Жёсткость адгезина» плюс демпфирование.
- Угловая пружина той же жёсткости удерживает точки крепления направленными друг на друга; силы прикладываются в точках крепления и создают крутящий момент.
- У клетки не больше 20 связей (жёсткий предел).

**Расход.** Каждый час клетка теряет массу = базовый расход типа × множитель солёности + доп. расход действий (плавание, секреция). Цитоскелет выше среднего удорожает создание клетки при делении. Ориентиры коэффициентов из описаний оригинала (нг/ч): липоцит 0; кератиноцит и глюоцит 0,01; сенсоцит и стереоцит 0,1; нейроцит 0,2; флагеллоцит 0,1–0,25 в зависимости от силы плавания; вироцит 2; фотоцит 2,5. Для остальных типов назначить значения самим и вынести в `SimConfig`.

**Смерть.** Масса ниже минимума (≈0,3 нг, настраивается), возраст 240 h при включённом старении, яд (цианид), смерть от радиации, касание стенки при «Гибели на краю». Погибшая клетка исчезает; по желанию — оставляет частицу пищи с частью массы (решение записать в `DECISIONS.md`).

**Обмен питанием по связям.** На каждом шаге по каждой связи A–B течёт масса, выравнивающая отношение «масса / приоритет питания». Поток пропорционален разности этих отношений и ограничен за шаг. Суммарная масса организма при обмене сохраняется (это проверяется тестом). «Приоритизировать» (по умолчанию вкл.): если масса клетки ниже порога опасности, её приоритет временно умножается в несколько раз, чтобы она не отдала последнее.

**Нитраты.** Каждая клетка хранит запас 0–1 и пополняет его из среды со скоростью параметра «Нитраты». Деление требует и тратит нитраты; остаток делится между потомками. Нитраты перетекают по связям; нитроцит производит их сам; секроцит тратит постоянно. Без достаточного запаса клетка не делится, но не умирает.

## Геном и деление

Геном — это 40 режимов (M1–M40); у каждой клетки активен ровно один режим, и он определяет её тип и поведение. Один режим помечен как начальный: с него растёт организм и он ставится синтезатором.

**Общие параметры режима:**

| Параметр | Тип и диапазон | По умолч. | Смысл |
| --- | --- | --- | --- |
| Тип клетки | выбор из 18 | Фагоцит | Раздел «Типы клеток» |
| Делать адгезин | вкл/выкл | выкл | Потомки при делении связываются друг с другом |
| Режим потомка 1 / 2 | M1–M40 | текущий | Режим, в который перейдёт каждый потомок |
| Сохранять связи потомка 1 / 2 | вкл/выкл | вкл | Унаследует ли потомок связи матери на своей стороне |
| Зеркально потомок 1 / 2 | вкл/выкл | выкл | Все углы потомка отсчитываются по часовой стрелке, а не против |
| Масса деления | «по возрасту 0,5 h» … 3,55 нг … «никогда» | \~2,5 нг | Порог массы для деления |
| Соотношение деления | 10:90 … 90:10 | 50:50 | Доля массы потомку 1 |
| Приоритет питания | 0–1 | 0,5 | Вес при обмене массой по связям |
| Приоритизировать | вкл/выкл | вкл | Защита от отдачи последней массы |
| Угол деления | 0–360° | 0° | Направление плоскости деления относительно «переда» |
| Угол потомка 1 / 2 | 0–360° | 0° | Поворот «переда» потомка относительно матери |
| Цвет R / G / B | 0–1 | — | Цвет клетки; виден сенсорам |
| Жёсткость адгезина | 0–1 | 0,5 | Активно при «Делать адгезин» |
| Длина адгезина | 0–1 | 0,5 | Длина покоя связи |
| Цитоскелет | 0–1 | 0,5 | Твёрдость клетки и цена её создания |
| Макс. связей | 0–20 | 20 | Клетка с таким числом связей не делится |

«Привязка значений» (редактор, по умолч. вкл.): углы шагом 15°, прочие ползунки — 25 дискретных уровней.

**Условия деления** — все сразу: масса ≥ массы деления; возраст ≥ 0,5 h; нитратов хватает; число связей < «Макс. связей»; в чашке не достигнут предел клеток.

**Геометрия деления:**

1. Плоскость деления проходит через центр под «Углом деления» к оси «переда»; потомок 1 оказывается с одной стороны, потомок 2 — с другой.
2. Масса делится по «Соотношению»; потомки ставятся вдоль нормали к плоскости так, чтобы едва касаться друг друга. Потомок с массой ниже минимума сразу погибает.
3. Ориентация потомка = ориентация матери + его «Угол потомка» (против часовой стрелки или по ней при «Зеркально»).
4. Каждая связь матери переходит к тому потомку, на чьей стороне плоскости лежит её точка крепления; если у потомка «Сохранять связи» выкл. — связь рвётся.
5. При «Делать адгезин» между потомками создаётся новая связь с жёсткостью и длиной этого режима.
6. Потомкам присваиваются режимы «Режим потомка 1/2», возраст обнуляется, нитраты делятся.

**Программируемые значения.** Ряд параметров типов (сила плавания, плотность, мышцы, реснички, выходы нейроцита, пороги стемоцита) задаётся не числом, а функцией от входа:

- линейная: значение = a × вход + b (a, b ∈ \[−4; 4\]);
- ступенчатая: значение = a, если вход < c, иначе b (a, b ∈ \[−0,5; 0,5\], c ∈ \[−1; 1\]).

Вход выбирается из: S1–S4, масса / 3,6 нг, возраст / 240 h, запас нитратов, число связей / 20. Без сигналов (a = 0) это просто константа b.

## Типы клеток

Каждая клетка выполняет ровно одну функцию — это упрощение, на котором держится весь геймплей. Всего 18 типов; столбец «Этап» указывает, в каком этапе разработки тип реализуется (раздел «Этапы»). Идентификаторы в коде — английские, в интерфейсе — русские названия.

| Тип (код) | Что делает | Свои параметры | Этап |
| --- | --- | --- | --- |
| Фагоцит (`PHAGOCYTE`) | Поглощает частицу пищи при касании и получает её массу; пищу с оболочкой не ест | — | 2 |
| Фотоцит (`PHOTOCYTE`) | Прирост массы пропорционален освещённости в своей точке; дорогой в содержании | — | 2 |
| Флагеллоцит (`FLAGELLOCYTE`) | Тянет себя и организм вперёд вдоль своей оси; доп. расход растёт с силой. Если сзади (место жгутика) прикреплена клетка — жгутик не работает (в оригинале клетка гибнет; сделать настраиваемым) | Сила плавания (программируемая) | 4 |
| Девороцит (`DEVOROCYTE`) | При касании чужой клетки высасывает из неё массу; не действует на защищённые клетки и на свой организм | — | 4 |
| Липоцит (`LIPOCYTE`) | Хранит большой запас массы, расход 0; отдаёт запас по связям; не пропускает сигналы. Липаза секроцита превращает его в пищу | — | 4 |
| Кератиноцит (`KERATINOCYTE`) | Защищает себя и напрямую связанные клетки от девороцитов, глюоцитов, вироцитов и секретов | — | 4 |
| Буйоцит (`BUOYOCYTE`) | Пузырь с настраиваемой плотностью: тонет или всплывает | Плотность (программируемая) | 4 |
| Глюоцит (`GLUEOCYTE`) | При касании создаёт связь с чужой незащищённой клеткой или со стенкой, если у него меньше 5 связей. С высоким приоритетом питания работает как паразит | — | 4 |
| Нитроцит (`NITROCYTE`) | Производит нитраты и отдаёт их по связям | — | 4 |
| Сенсоцит (`SENSEOCYTE`) | Выдаёт сигнал, пропорциональный силе «запаха» | Что чуять, канал S1–S4, выход, порог цвета | 6 |
| Стереоцит (`STEREOCYTE`) | Как сенсоцит, но знак сигнала зависит от стороны: раздражитель справа — плюс, слева — минус | Как у сенсоцита | 6 |
| Миоцит (`MYOCYTE`) | Мышца: тянет или толкает связи спереди и сзади, изгибается вправо/влево, приподнимает соседей | Сокращение, изгиб, подъём (программируемые) | 6 |
| Нейроцит (`NEUROCYTE`) | 4 выходных канала; каждый выдаёт константу или функцию входа; режим осциллятора (синус между двумя каналами) | 4 программируемых выхода, частота осциллятора | 6 |
| Стемоцит (`STEMOCYTE`) | Без деления переходит в режим пути 1 или 2, когда сигнал пути > 0,5 | Режим и сигнал пути 1 и 2 | 6 |
| Секроцит (`SECROCYTE`) | Выделяет в окружающую среду: запах пищи, цианид (убивает незащищённые клетки), сигнальное вещество, липазу; тратит нитраты | Вещество, интенсивность | 6 |
| Вироцит (`VIROCYTE`) | При касании копирует выбранный режим и все режимы, достижимые из него делениями, в геном жертвы и переводит её в этот режим | Какой режим копировать | 7 |
| Гамета (`GAMETE`) | Не делится; при касании совместимой гаметы сливается с ней в клетку с рекомбинированным геномом (каждый режим берётся от одного из родителей) и переходит в заданный режим | Режим после слияния | 7 |
| Цилиоцит (`CILIOCYTE`) | Реснички слева и справа двигаются независимо; клетка ползает по соседям и стенке | Скорость левых и правых ресничек (программируемые) | 7 |

Каждый тип рисуется узнаваемо, но в собственном стиле: например, фотоцит — зёрна хлоропластов, флагеллоцит — волнистый хвост сзади, кератиноцит — двойная мембрана, липоцит — капли жира. Цвет мембраны берётся из RGB режима.

## Сигналы

Сигналы — это четыре одинаковых по свойствам вещества S1–S4, которые позволяют организму чувствовать среду и управлять движением. Без них организмы двигаются вслепую; с ними можно собрать «умного пловца», который поворачивает к пище.

**Хранение и распространение:**

- У каждой клетки четыре числа S1–S4 (могут быть отрицательными).
- Сигнал течёт по адгезионным связям, выравниваясь между соседями, и экспоненциально затухает со временем. Чем больше у клетки связей, тем сильнее разбавляется её выход.
- Липоцит сигнал не пропускает (служит изолятором).
- Положительный и отрицательный сигнал одного канала складываются и могут взаимно погаситься; разные каналы независимы.

**Источники:** сенсоцит, стереоцит, нейроцит, секроцит (выпускает сигнальное вещество в среду рядом с собой).

**Потребители** — через программируемые значения (раздел «Геном»): сила плавания флагеллоцита, плотность буйоцита, мышцы миоцита, реснички цилиоцита, пути стемоцита, выходы нейроцита.

**Что чуют сенсоры** (параметр «Что чуять»):

| Вариант | Сила раздражителя |
| --- | --- |
| Клетки | Клетки, чей цвет близок к заданному порогом цвета; свои тоже учитываются |
| Пища | Частицы пищи без оболочки |
| Пища с оболочкой | Частицы с липидной оболочкой |
| Свет | Освещённость в точке |
| Скорость | Собственная скорость клетки |
| Стенка | Близость стены чашки |

Сила запаха = сумма вкладов объектов в радиусе чувствительности с весом, убывающим с расстоянием (например 1/(1+d²)). Поиск — через ту же хеш-сетку, что и столкновения. Стереоцит считает проекцию направлений на свою поперечную ось: раздражители справа дают плюс, слева — минус.

Контрольный сценарий для этапа 6: организм «стереоцит + два флагеллоцита по бокам», где правый флагеллоцит берёт a ≈ 0,76, а левый — a ≈ −0,76 от того же канала, должен заметно поворачивать к ближайшей пище.

## Мутации и эволюция

Эволюция — главное, ради чего существует игра: радиация вносит случайные изменения в геном, а среда отбирает выживших. Никакой «функции приспособленности» нет — отбор возникает сам из физики, питания и конкуренции.

**Геномы в памяти.** Геном неизменяем и разделяется между клетками по ссылке. Мутация создаёт новую копию генома только для мутировавшей клетки (copy-on-write); её потомки наследуют новую копию. Каждый геном получает id и id родителя — это даёт счётчик «видов» и родословную для статистики.

**Частота.** Вероятность мутации клетки за час = f(уровень радиации), калибруется так, чтобы при 0,03–0,05 изменения были заметны за десятки часов, а при 1 геном быстро разрушался. При высокой радиации клетка также может погибнуть с малой вероятностью.

**Виды мутаций:**

- Точечная (всегда разрешена): у случайного режима меняется случайный непрерывный параметр — гауссов сдвиг с отсечкой по диапазону (масса деления, углы, цвет, приоритет, коэффициенты a/b/c и т. п.).
- Структурная (только если «Только точечные мутации» выкл.): смена типа клетки на тип из генофонда, смена режима потомка, переключение флагов (адгезин, сохранение связей, зеркальность), копирование одного режима поверх другого.
- Мутация затрагивает геном самой клетки; её текущий режим меняется сразу, остальные — проявятся у потомков.

**Заражение случайными клетками.** При включённой опции раз в несколько часов в случайное место чашки добавляется клетка со случайным, но валидным геномом из типов генофонда.

**Валидность.** После любой мутации геном проходит проверку: ровно один начальный режим, все индексы режимов в 0–39, все значения в своих диапазонах. Это проверяется тестом на тысячах случайных мутаций.

## Интерфейс

Три основные вкладки внизу экрана — «Микроскоп», «Геном», «Среда» — плюс «Генбанк». Интерфейс на русском (`strings.xml`), основная ориентация портретная, ландшафт тоже поддерживается.

**Микроскоп** (главный экран):

- Полноэкранный GL-вид чашки: щипок — зум, двумя пальцами — сдвиг, двойной тап — вписать чашку в экран.
- Верхняя панель: возраст субстрата, число клеток, число частиц пищи, кнопки «Заморозка / Наблюдение / Инкубация».
- Нижняя панель инструментов: синтезатор, пинцет, подкормка, удаление, диагностика (раздел «Мир»).
- Диагностика: тап по клетке — камера следует за ней; карточка показывает режим, тип, массу, возраст, нитраты, S1–S4, число связей и кнопку «Копировать геном».
- Отображение: тёмный фон, мембрана цветом режима, ядро, признаки типа; связи — тонкие линии; пища — мелкие точки (с оболочкой — красные); свет — мягкое свечение со стороны источника.

**Геном** (редактор):

- Сверху — превью роста организма из начального режима: отдельная мини-симуляция с бесконечной пищей и светом, до 64 клеток, ползунок времени 0–47 h. Клетка редактируемого режима обведена; тап по клетке превью выбирает её режим.
- Под превью — выбор режима M1–M40 и все параметры режима: ползунки с привязкой значений, переключатели, выпадающие списки режимов потомков, затем параметры, специфичные для типа.
- Тап по названию параметра — короткая справка, написанная нами (не из оригинала).
- Программируемые значения: выбор формы (линейная / ступенчатая), входа и ползунки a, b, c с маленьким графиком функции.
- Превью пересчитывается автоматически после изменения (с задержкой \~300 мс, в фоне).

**Среда:** все параметры из таблицы раздела «Мир», сгруппированные: «Пища», «Свет», «Физика», «Химия», «Эволюция», «Правила»; кнопки «Сохранить чашку», «Загрузить», «Стерилизовать».

**Генбанк:** список сохранённых геномов с миниатюрой; «Загрузить с микроскопа» (геном клетки под диагностикой), «Геном по умолчанию», сохранение под именем (то же имя — перезапись), экспорт и импорт через системное меню «Поделиться» и выбор файла.

**Производительность (критерии на Poco X7 Pro):** 60 кадров/с при 1000 клеток; в «Наблюдении» симуляция не отстаёт от реального времени при 2000 клеток; «Инкубация» использует всю свободную мощность фонового потока, не блокируя интерфейс.

## Сохранение

Всё хранится в собственных форматах на JSON с полем версии; формат оригинала не поддерживается.

| Что | Формат и расширение | Где |
| --- | --- | --- |
| Геном | JSON: `formatVersion`, имя, индекс начального режима, массив из 40 режимов со всеми параметрами; `.petri-genome.json` | Внутренняя папка приложения; экспорт через «Поделиться» |
| Чашка | gzip(JSON): настройки среды, возраст, клетки, связи, пища, все используемые геномы, seed генератора; `.petri-dish.gz` | Внутренняя папка; слоты сохранения |
| Настройки приложения | DataStore | Системное хранилище |

Правила:

- Автосохранение текущей чашки и генома при уходе приложения в фон; восстановление при запуске.
- Миграции между версиями формата: старый файл читается и переводится в новую версию, а не отвергается.
- Импорт битого файла не роняет приложение: показать понятную ошибку.
- Тест: геном и чашка после записи и чтения совпадают с исходными (round-trip).

## Этапы и критерии приёмки

Работа идёт по восьми этапам; после каждого собирается APK, пользователь проверяет его на телефоне, и только потом начинается следующий этап. Каждый этап заканчивается рабочей игрой, а не полуфабрикатом.

0. **Каркас.** Проект, модули `app` и `sim`, GitHub Actions, пустая чашка в GL-виде с зумом.
   - APK из Releases ставится на Poco X7 Pro и открывается; в APK нет папки `lib/`.
1. **Физика и деление.** Клетки-диски, столкновения, стенка, связи с точками крепления, деление по геному с углами, зеркальностью и наследованием связей; рендер.
   - Геном «M1 делится на M1 + M1 с адгезином» растёт в устойчивую колонию без «взрывов» и дрожания.
   - Цепочка с углом деления 90° растёт прямой линией; с углом потомка 15° — дугой.
2. **Питание и смерть.** Пища и её спавн, свет, фагоцит и фотоцит, расход, обмен по связям, приоритизация, нитраты, смерть, предел клеток.
   - Колония фотоцитов при узком луче света растёт к источнику и выходит на плато.
   - Тест: суммарная масса организма при обмене по связям сохраняется.
3. **Редактор генома и генбанк.** Все общие параметры, превью роста, сохранение, импорт и экспорт.
   - Изменение угла деления видно в превью меньше чем через секунду; геном переживает экспорт → импорт.
4. **Базовые типы.** Флагеллоцит, девороцит, липоцит, кератиноцит, буйоцит, глюоцит, нитроцит; гравитация, плотность, трение; все параметры среды.
   - «Пловец» (фагоцит + флагеллоцит, фагоцит отщепляет спору) плавает, ест и размножается.
   - Девороциты истребляют незащищённую колонию, но не колонию с кератиноцитами.
5. **Эволюция.** Радиация, точечные и структурные мутации, генофонд, заражение случайными клетками, счётчик видов.
   - При радиации \~0,04 за 50 h появляются заметные вариации цвета и формы; при 1 популяция деградирует.
6. **Сигналы.** S1–S4, сенсоцит, стереоцит, миоцит, нейроцит, стемоцит, секроцит, программируемые значения в редакторе.
   - Контрольный «умный пловец» из раздела «Сигналы» поворачивает к пище.
7. **Остальное и полировка.** Вироцит, гамета, цилиоцит, справка по параметрам, график численности, иконка и экран «О приложении».
   - Производительность соответствует критериям из раздела «Интерфейс».

## Указания для Claude Code

Этот документ кладётся в корень репозитория как `SPEC.md`; первая команда исполнителю — «Прочитай SPEC.md целиком и выполни этап 0». Дальше — по одному этапу за раз.

**Порядок работы:**

- Перед этапом коротко опиши план и файлы, которые затронешь; после этапа — коммит, тег `v0.<этап>.0`, запись в `CHANGELOG.md` и инструкция пользователю, что проверить на телефоне.
- Если механика описана неполно — выбирай простейший играбельный вариант, записывай решение в `DECISIONS.md` и не останавливайся ради вопросов. Спрашивай пользователя только о вкусовых вещах (как выглядит, как ощущается).
- Не декомпилируй и не скачивай оригинальный APK, не ищи и не используй его код, графику и тексты. Описания механик в этом ТЗ — достаточная основа.
- Пользователь — не программист: инструкции в README и после этапов пиши пошагово, без жаргона.

**Код:**

- Модуль `sim` не зависит от Android и детерминирован: одинаковый seed и одинаковые действия дают одинаковый результат.
- Все числовые константы — в `SimConfig.kt` с комментарием, что они означают; никаких «магических чисел» в логике.
- Горячий цикл без аллокаций: массивы примитивов, пул связей, пространственная хеш-сетка, переиспользуемые буферы.
- Рендер читает снимок состояния через двойную буферизацию; симуляция и рендер в разных потоках.

**Тесты (JUnit в `sim`):**

- Геометрия деления: позиции, углы и зеркальность потомков; наследование связей.
- Сохранение массы при обмене по связям.
- Устойчивость: цепочка из 50 клеток с максимальной жёсткостью не разлетается за 1000 шагов.
- Валидность генома после 10 000 случайных мутаций.
- Round-trip сериализации генома и чашки.
- Бенчмарк шага на 2000 клеток с выводом времени в лог CI.
